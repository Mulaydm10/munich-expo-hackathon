# Glossary

Cheap now, pays off the moment a second agent/human joins and naming starts to drift. Add a term
the first time it would otherwise need explaining twice.

| Term | Meaning |
|---|---|
| Main Agent | The person/agent holding sole edit authority over LOCKED files (see `GOVERNANCE.md`); currently `Mulaydm10`. |
| LOCKED | A file category — edits require Main Agent + an audit-table entry. See `GOVERNANCE.md`. |
| Claim | A row in `STATE.md`'s work-claims table reserving a surface; release it the moment you stop. |
| `ADR-####` | An architecture/process decision record, in `design/decisions/`. |
| `Q-####` | An open question, in `research/open_questions.md`. |
| `EXP-####` | An experiment/spike, in `experiments/experiment_log.md`. |
| `DEMO-####` | A judge-facing demo scenario, in `DEMO.md`. |
